# 실지출 트래커

내가 한 번에 결제하고 친구들이 나중에 돈을 보내주면, 은행 앱은 결제를 지출로, 친구들 송금을 수입으로 따로 적어요.
이 앱은 그 송금을 원래 결제에 연결해서 **내가 실제로 쓴 돈**을 보여줘요.

- AI(Claude)가 지출을 카테고리(식비·편의점·술·유흥·구독료·교통비·쇼핑·생활·송금·기타·제외)로 분류
  - 친구 송금·페이 결제처럼 거래마다 용도가 다른 항목과 AI가 확신하지 못한 항목은 **거래 → 분류 확인**에 모여요
  - '제외'(환전·투자·저축)는 실지출에서 빠져요
- 친구 송금이 어느 결제의 더치페이인지 AI가 연결을 제안 → 내가 확정
- 결제 취소(토스의 플러스 금액 체크카드결제)는 원래 결제에 자동 연결
- 이번 달 실지출, 이번 주 막대, 카테고리별 비율, 예산 대비 현황
- 예산·지난 주와 비교해 줄일 수 있었던 곳을 짚어주는 주간 보고서

## 처음 시작하기 (팀원용)

필요한 것: Python 3.11 이상, [Anthropic API 키](https://console.anthropic.com) (각자 발급)

1. 저장소를 받아요.

   ```bash
   git clone <저장소 주소>
   cd spending-tracker
   ```

2. 패키지를 설치해요.

   ```bash
   pip install -r requirements.txt
   ```

3. `.env.example`을 복사해 `.env`를 만들고 `ANTHROPIC_API_KEY=` 뒤에 **자기** 키를 넣어요.

   ```bash
   copy .env.example .env
   ```

   키가 없어도 앱은 켜지지만, AI 분류·정산 제안·보고서는 꺼져요.

4. 서버를 켜요. Windows는 `start.bat`을 더블클릭해도 돼요.

   ```bash
   python -m uvicorn app.main:app --reload
   ```

5. 브라우저에서 http://127.0.0.1:8000 을 열고, 아래 **＋** 버튼으로 `samples/sample_toss.pdf`(비밀번호 `900101`)를 올려 보세요.
   연습용 가짜 거래내역이에요.

화면 디자인을 맡았다면 [DESIGN.md](DESIGN.md)부터 보세요. 서버나 API 키 없이 작업할 수 있어요.

## 공유하면 안 되는 것

- `.env` — API 키. 다른 사람이 가져가면 내 계정으로 요금이 나가요.
- `data/` — 내 실제 거래내역이 담긴 DB.
- 실제 거래내역서 PDF·엑셀.

`.gitignore`가 이것들을 막고 있어요. 커밋하기 전에 `git status`로 한 번 더 확인해 주세요.

## 사용법

1. 토스 앱에서 토스뱅크 통장 → 거래내역 → 거래내역서 발급으로 PDF를 받아요. 엑셀·CSV도 올릴 수 있어요.
2. 아래 **＋** 버튼으로 올려요. PDF에 비밀번호가 걸려 있으면 비밀번호 칸에 넣어요.
3. **정산**에서 AI가 연결한 송금을 확정하거나 거절해요. 확정한 금액만 실지출에서 빠져요.
4. **거래 → 분류 확인**에서 친구 송금·페이 결제의 용도를 골라요.
5. 홈 오른쪽 위 톱니바퀴에서 카테고리별 한 달 예산을 정해요.
6. **보고서**에서 주를 고르고 보고서를 만들어요.

PDF는 표를 먼저 읽고, 표가 안 잡히면 날짜로 시작하는 줄을 읽고, 그래도 안 되면 AI가 PDF 텍스트를 읽어 거래를 정리해요
(이때 PDF 텍스트가 Claude API로 전송돼요).

## 정산 규칙

- 정산 후보: 결제 후 7일 안에 들어온 입금 중 결제액보다 작은 것 (급여·이자·환불 등은 제외)
- 실지출 = 결제액 − 확정한 정산 입금의 합 (0원 아래로는 내려가지 않음)
- 확인 대기 중인 정산은 실지출에 반영하지 않고 "확정하면 얼마"로 따로 보여줘요.
- 비상금처럼 내 계좌끼리 오간 돈은 가져오지 않아요.

## 구조

| 경로 | 하는 일 |
|---|---|
| `app/parser.py`, `app/pdf_reader.py` | PDF·엑셀·CSV → 거래 목록 |
| `app/settle.py`, `app/stats.py` | 정산 후보 규칙, 실지출 집계 (AI 없음) |
| `app/agent/` | Claude 호출: 카테고리 분류, 정산 매칭, PDF 추출, 주간 보고서 |
| `app/service.py` | DB와 위 모듈을 엮는 앱 동작 |
| `app/main.py` | FastAPI 서버 |
| `static/` | 화면 (HTML·CSS·JS, 빌드 과정 없음) |
| `docs/superpowers/` | 설계 문서와 구현 계획 |

## 공유용 데모 페이지

서버 없이 브라우저에서 돌아가는 데모를 HTML 한 파일로 만들 수 있어요. 화면은 `static/`을 그대로 쓰고,
서버 대신 `demo/mock_api.js`가 연습용 가짜 거래로 응답해요(업로드·AI 호출은 막혀 있음).

```bash
python demo/build_demo.py
```

결과는 `demo/dist/spending-demo.html`에 생겨요. 화면을 고친 뒤 다시 실행하면 최신 화면으로 다시 만들어져요.
