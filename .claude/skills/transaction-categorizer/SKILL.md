# 거래 분류 규칙집

실지출 트래커의 출금 거래를 사용자의 카테고리로 나눈다.
목표는 "사용자가 직접 골랐을 카테고리"를 맞히는 것이다. 사전적으로 맞는 답이 아니라 이 사용자의 습관이 정답이다.

## 1. 찾아보는 순서 (매번 지킨다)

1. **user_choices** — 같은 가게·같은 사람 이름으로 사용자가 고른 정답이 있으면 그대로 따른다. 가장 강한 단서다.
2. **nearby_transactions** — 앞뒤 3시간 거래를 본다. 페이 결제·송금은 거의 항상 앞뒤 거래가 답을 알려 준다.
3. **find_transactions** — 같은 날 전체, 같은 요일·시간대, 같은 금액이 반복되는지 본다.
4. **settlement_info** — 친구들이 나눠 낸 결제였는지 본다. 정산이 붙은 결제는 모임 비용이다.
5. 그래도 모르면 이름에서 업종을 짐작하고 confidence를 low로 낸다.

한 거래에 도구를 너무 많이 쓰지 않는다. 같은 날 거래는 한 번 조회해서 함께 판단한다.

## 2. 카테고리 정의

| 카테고리 | 넣는 것 | 헷갈리면 |
|---|---|---|
| 식비 | 식당, 학식, 분식, 패스트푸드, 배달앱 | 술집이 아닌 고깃집·식당의 저녁은 식비 |
| 편의점 | 편의점, **마트·슈퍼·할인점·생협 매점·휴게소 매점**, 무인 아이스크림 할인점 | 소액이라고 유흥·생활·기타로 보내지 않는다 |
| 술 | 술집, 호프, 포차, 이자카야, 와인바 | 이름에 술집 단서가 없으면 식비 쪽 |
| 유흥 | 카페·디저트, 만화카페, PC방, 노래방, 보드게임, 방탈출, 영화, 공연, 게임 | 데이트·여행 중이면 그쪽이 우선 |
| 구독료 | 매달 같은 날 같은 금액의 정기결제 | |
| 교통비 | 택시, 버스·지하철, 교통카드 충전, 주유, 주차, 따릉이 | 밤늦게·이른 아침 1~2만원 페이 결제는 택시일 때가 많다 |
| 쇼핑 | 온라인몰, 옷, 전자기기, 화장품 | |
| 생활 | 미용실, 통신요금, 생활용품, 인쇄, 세탁, 병원, 약국 | 마트 장보기는 생활이 아니라 편의점 |
| 데이트 | 연인과 함께 쓴 돈 (식사·카페·영화·놀거리) | **다른 카테고리보다 우선** |
| 여행 | 여행 중 쓴 돈 (숙소·교통·현지 식비·입장료) | **다른 카테고리보다 우선** |
| 송금 | 용도를 정말 알 수 없는 사람 간 송금 | 거의 쓰지 않는다 (4장) |
| 기타 | 어디에도 넣기 어려운 것 | 마지막 수단 |
| 제외 | 지출이 아닌 돈의 이동 (본인 계좌·저축·투자·환전) | |

## 3. 우선순위가 있는 카테고리

**데이트와 여행은 "어디서"보다 "언제·누구와"로 정한다.**

- 같은 날 앞뒤에 사용자가 데이트로 고른 거래가 있으면, 그날 이어진 식당·카페·놀거리·페이 결제도 데이트다.
- 데이트는 보통 몇 시간 안에 식사 → 카페·놀거리 → 교통이 이어진다. 이 흐름이 보이면 묶어서 판단한다.
- 여행으로 고른 거래가 이어지는 기간(숙소, 고속도로, 다른 지역 가게)의 교통·식사·송금은 여행이다.
- 고속도로 휴게소가 여행 기간 밖이면 휴게소 식당은 식비, 매점은 편의점이다.

## 4. 사람 이름(송금)과 페이 결제

이 사용자는 친구에게 보낸 돈도 **용도로** 분류한다. "송금"을 고르는 일은 드물다.

- 앞뒤 몇 시간 안에 술집 결제가 있으면 → 술
- 노래방·PC방·카페·보드게임 등이 있으면 → 유흥
- 여행 기간이면 → 여행, 데이트 중이면 → 데이트
- 친구가 먼저 결제하고 내가 내 몫을 보낸 경우가 많다. 금액이 근처 결제를 사람 수로 나눈 값과 비슷하면 그 결제의 카테고리를 따른다.
- 단서가 하나도 없을 때만 송금, 그것도 confidence low.

토스페이·카카오페이·결제대행사(나이스, KG이니시스 등) 이름은 업종이 아니다. 반드시 앞뒤 거래와 금액·시간으로 추리한다.

## 5. 처음 보는 가게 이름

- "(주)○○", "○○산업", "○○유통"처럼 법인명만 있는 가게는 이름 속 단어를 본다.
  - 마트·리테일·유통·슈퍼·하이웨이(마트 운영사) → 편의점
  - 휴게소(○○방향) → 3장 규칙
  - 필름·포토 → 사진관(유흥, 데이트 중이면 데이트)
- 같은 가게에서 여러 번 비슷한 소액(2천~1만원)을 냈다면 장보기일 가능성이 높다 → 편의점.
- 웹 검색 도구가 있으면 법인명을 검색해 업종을 확인한다. 없으면 짐작하고 low.

## 6. 기타는 마지막 수단

단서가 하나라도 있으면 그 카테고리를 고르고 confidence를 낮춘다. "모르겠다"는 이유로 기타를 고르지 않는다.

## 7. 답 형식

- 맡은 거래 전부를 submit_guesses로 한 번에 낸다.
- confidence
  - high: 같은 이름의 사용자 정답이 있거나, 이름이 업종을 분명히 말한다
  - medium: 앞뒤 거래로 추리했다
  - low: 단서가 거의 없다
- reason: 판단에 쓴 단서를 한국어 한 문장으로 쓴다. 예: "결제 5분 전 같은 건물 노래방 결제가 있어 유흥".

## 예시

| 거래 | 단서 | 답 |
|---|---|---|
| 카카오페이 9,800원 (토 15:10) | 15:00 보드게임카페, 같은 날 데이트로 고른 식당 | 데이트 |
| 김○○ 12,000원 (금 23:40) | 23:00 호프집 48,000원 (÷4 = 12,000) | 술 |
| 토스페이 13,500원 (수 01:20) | 앞뒤 결제 없음, 새벽, 1만원대 | 교통비 (medium) |
| (주)○○리테일 3,200원 | 같은 가게 소액 반복 | 편의점 |
| ○○휴게소(서울방향) 8,000원 | 앞 이틀간 다른 지역 숙소·식당 | 여행 |
| 이○○ 50,000원 | 앞뒤 거래 없음, 정산 없음 | 송금 (low) |
